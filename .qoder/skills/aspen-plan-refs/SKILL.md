# model_plan 起草参考

## 1. 物性方法决策树（按顺序问，第一个命中即定）

1. 体系有离子 / 电解质 / 酸碱 / 胺 / 盐？→ **ELECNRTL**
2. 有聚合物？→ **POLYNRTL**
3. 纯水 / 蒸汽体系？→ **STEAMNBS**
4. 有极性组分（醇 / 酮 / 酸 / 水 / 胺）且要算 VLE？→ **NRTL-RK / UNIQUAC / WILSON**
5. 组分非极性（轻烃 / 天然气 / 炼厂气）？→ **PENG-ROB / PR-BM / RK-SOAVE**
6. 重烃 / 原油 / 宽馏分？→ **BK10 / CHAO-SEA**
7. 以上都不是 → **PENG-ROB**（安全缺省）

**有共沸必须用活度系数模型**（NRTL-RK 系）。EOS 抓不住共沸，会给出"看似收敛但全错"的分离结果。

## 2. 常见体系速查

| 体系 | 首选方法 | 有无共沸 |
|---|---|---|
| 轻烃 C1–C5 | PENG-ROB | 无 |
| 芳烃 BTX | PENG-ROB / NRTL-RK | 无 |
| 乙醇 / 异丙醇 + 水 | NRTL-RK | **有** |
| 甲醇 + 水 | NRTL-RK | 无 |
| 电解质 / 酸碱 / 酸性水 / 胺法脱硫 | ELECNRTL | — |
| 纯水蒸汽 | STEAMNBS | — |

## 3. BIP 完备性 —— 最贵的静默错误

活度系数模型下，数据库没有的二元对 Aspen 会**静默取 0 或用 UNIFAC 估算**，照样
"收敛"但结果错。
- model_plan §3 必须列**关键二元对清单**（决定塔顶/塔底分离的对）
- 常见数据库自带 BIP：甲醇-水、乙醇-水、丙酮-水、苯-甲苯（近理想）
- 生僻对在清单标"待核查"，engineer 在 SETUP BIP 核查时确认，缺失记 note 不沉默

## 4. 可达性上限（model_plan §3 主动点出）

| 体系 | 常压共沸点 |
|---|---|
| 乙醇-水 | ~95.6 wt% 乙醇 |
| 异丙醇-水 | ~87.7 wt% IP |
| THF-水 | ~95 wt% THF |

甲醇-水、苯-甲苯**无共沸**，可精馏到高纯。
指标涉及分离纯度 / 转化率时先判物理可达，不可达就在 model_plan 明确标出，
别让用户建完才知道到不了。
- **溶解气类**：极性溶剂（甲醇 / 水等）会吸收 CO2 / N2 等轻气，气体纯度、
  脱除率类指标须把溶解损失计入可达性（实测教训：甲醇产品 0.54 mol% CO2
  无脱除路径）

## 5. 常识区间（定参数用）

- 常压精馏塔板数：20–60；回流比：1.2–5.0（最小回流比的 1.2–1.5 倍）
- 进料板：塔板数的 1/3–1/2 处
- 冷却水：25 C 进 / 35–40 C 出
- 低压蒸汽：3–5 bar（120–150 C）；中压：10–15 bar（180–200 C）

## 6. 单位约定（model_plan 唯一写法）

- 数值一律“工程值 + 单位”书写（150 C、10 bar、100 kmol/hr），**不写 SI 换算列**
- engineer 用 `configure_model(manifest)` 批配置提交：数值 spec 显式 unit（enum/text
  不带 unit）；主 agent 与 model_plan 不做任何换算，不手工换算绕行
- 无量纲量标注“无量纲”；进料组成**显式声明组成基准与总量基准**：分数基准
  （MOLE-FRAC/MASS-FRAC）配显式正总流量，流量基准（MOLE-FLOW/MASS-FLOW）配组分
  流量求和；不写“默认 MOLE-FLOW”这类隐含默认
- 组分标签 > 8 字符会被截断，model_plan §2 给预期标签；杂质/惰性行必含
- 压力剖面逐节点给（§6），防压力倒挂
- §4 进料表补组成基准/总量基准两列；执行预算（首跑 1、TUNE 另授 ≤3、简单案例
  deadline 300 秒）写进 model_plan §8，方便 engineer 与派发 prompt 追溯 manifest
